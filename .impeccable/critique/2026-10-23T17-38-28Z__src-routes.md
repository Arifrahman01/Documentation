#### Design Specificity Verdict

**LLM assessment**: Category-interchangeable SaaS shell masking a specific enterprise workflow. While the portal serves a genuinely specific enterprise domain (SAP ERP ABAP/RFC/BAPI/CDS Views, SAP Analytics Cloud FSD vs. Story Builder Specs, and 7 internal operational apps), its visual presentation leans on an unmodified monochrome Shadcn UI template that repeatedly breaks the fourth wall to advertise its own tech stack ("komponen Shadcn UI yang seragam"). Furthermore, `/apps` treats mission-critical systems (like Fuel Management System) identically to utility apps, and neither of the two competing editors allows authoring or updating the `builderContent` tab on SAC documentation pages.

#### Overall Impression
The portal has a solid functional core—especially the separation between Scoped Document AI (`Ctrl+I`) and Global Copilot (`Ctrl+J`), inline image pasting, and scroll-spy outline navigation—but suffers from architectural split-brain (two separate editors, two backend implementations, two upload routes) and critical UX guardrails missing in the primary authoring flow.

#### What's Working
1. **Scoped Document AI vs. Global Copilot Separation (`src/lib/components/docs/DocAiAssistantModal.svelte:201-221` & `src/routes/docs/[...slug]/+page.svelte:1747-1768`)**: Distinguishing between a single-document AI Spotlight (`Ctrl+I`) with a `"Lingkup Terkunci"` badge and a Global Copilot (`Ctrl+J`), plus the ability to pin AI takeaways to the top of the article (`"Sematkan di Artikel"`), directly prevents cross-document hallucination.
2. **Frictionless Image Paste & Inline Note Creation (`src/routes/docs/[...slug]/+page.svelte:543-586, 1106-1164`)**: Creating a note directly inside a folder and pasting clipboard screenshots (`Ctrl+V`) with optimistic Markdown placeholders makes documenting SAP GUI / SAC workflows fast.
3. **Interactive Right Outline with Scroll-Spy (`src/routes/docs/[...slug]/+page.svelte:638-686`)**: Smooth offset scrolling paired with `IntersectionObserver` active state tracking keeps long technical specs easy to navigate.

#### Priority Issues

- **[P0] What**: Unprotected Data Loss in Inline Editor & Divergent Dual-Editor Architecture (`src/routes/docs/[...slug]/+page.svelte:523-531, 822, 1440` & `src/lib/components/DocEditorModal.svelte:539-1077`)
  - **Why it matters**: Clicking `"Batal"` or pressing `Escape` in the inline editor immediately discards all unsaved changes without confirmation or `localStorage` draft recovery. Clicking AI actions (`"Tulis AI"`, `"Rapikan"`) overwrites `inlineContent` with no Undo. Meanwhile, `/apps` uses a separate modal editor (`DocEditorModal.svelte`) with a different upload endpoint and locked metadata fields, and neither editor can edit `builderContent`.
  - **Fix**: Add dirty-state confirmation, `localStorage` draft auto-save, and an AI Undo snapshot to the inline editor; expose `builderContent` and metadata fields; consolidate the two editors and upload routes.
  - **Suggested command**: `/impeccable harden`

- **[P1] What**: Complete Absence of Mobile/Tablet Sidebar Navigation & Pillar Switcher (`src/routes/docs/[...slug]/+page.svelte:223-226, 1069, 1799`)
  - **Why it matters**: The File Explorer sidebar is `hidden lg:block`, leaving viewports `<1024px` (tablets, mobile, or split-screen laptops next to SAP GUI) with no way to browse or create documents. Even on desktop, the sidebar locks to the current pillar (`SAP`, `SAC`, or `WEB`) with no switcher.
  - **Fix**: Add a mobile drawer trigger (`lg:hidden`) for the File Explorer & Outline, add a `SAP | SAC | WEB | Semua` pillar switcher at the top of the File Explorer, and add a UI button for the orphaned `isFocusMode` state.
  - **Suggested command**: `/impeccable adapt`

- **[P1] What**: Aggressive Single-Key & Browser Shortcut Hijacking (`src/routes/docs/[...slug]/+page.svelte:837-895` & `src/routes/+layout.svelte:35-54`)
  - **Why it matters**: Bare keys (`e`, `n`, `f`, `i`) are captured on `window`, hijacking screen-reader navigation keys, while `Ctrl+N` and `Alt+F` override browser shortcuts, and pressing `Ctrl+E`/`Ctrl+I` on `/apps` forcefully redirects the user to `/docs/sap/overview`.
  - **Fix**: Remove bare single-key global listeners and browser-reserved shortcuts (`Ctrl+N`, `Alt+F`), and remove the cross-route redirect in `+layout.svelte`.
  - **Suggested command**: `/impeccable harden`

- **[P2] What**: Hidden Edit/Delete Actions & Silent API Failures in Program Navigator (`src/routes/apps/+page.svelte:298-344, 457, 581-656`)
  - **Why it matters**: Editing or deleting an app card is only accessible via right-click (`oncontextmenu`), making it undiscoverable and unusable on touch/keyboard devices. Saving or deleting a program also has no error handling when the API fails.
  - **Fix**: Add a visible `MoreHorizontal` (`...`) action menu button on each program card and render API error feedback inside the Program Modal.
  - **Suggested command**: `/impeccable clarify`

- **[P2] What**: Cognitive Overload in Modals, Tabs, and Duplicate AI Triggers (`src/routes/apps/+page.svelte:420-428`, `src/lib/components/DocEditorModal.svelte:808-950`, `src/lib/components/Header.svelte:140-150`, `src/lib/components/AiCopilot.svelte:179-188`)
  - **Why it matters**: `/apps` renders 7 category tabs for just 7 total apps; `DocEditorModal` crowds 13 toolbar buttons + 5 AI/template buttons into one view; and two `"AI Copilot (Ctrl J)"` buttons appear simultaneously on every page.
  - **Fix**: Consolidate duplicate AI Copilot triggers, simplify toolbar groupings, and synchronize the landing page onboarding copy with the actual UI.
  - **Suggested command**: `/impeccable distill`
